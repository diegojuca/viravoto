# Vamos virar juntos — onde seu voto vira mais votos

Página estática para a militância: encontre sua cidade e seu local de votação e veja o que fazer até o 2º turno (25/10/2026).

**Material produzido por apoiadores, sem vínculo oficial com a campanha. Responsável: Diego Jucá.**

- Fontes: TSE (resultados oficiais do 2º turno de 2022 e do 1º turno de 2026, por seção e local de votação; cadastro de locais), IBGE (Censo 2022), MDS (Bolsa Família), CGU/Portal da Transparência (Pé-de-Meia), Ministério da Saúde (Mais Médicos).
- A classificação de cidades e locais é uma estimativa feita a partir dos resultados oficiais agregados. Não indica o voto de nenhuma pessoa e não contém dados pessoais.
- Gerado automaticamente a partir de um pipeline de dados abertos; não edite os arquivos à mão.
